# 同步状态弹窗回归测试清单

## 适用范围

- `popup.html` / `popup.js` 中的同步状态弹窗
- 已配置同步服务、自动同步开关、手动同步按钮状态

## 回归场景

1. WebDAV 已配置且自动同步已开启
   - 打开 popup，点击同步按钮。
   - 弹窗展示 WebDAV 同步服务项。
   - 服务项展示自动同步已开启。
   - 点击同步按钮可以触发一次手动同步。

2. WebDAV 已配置且自动同步已关闭
   - 在设置页保存有效 WebDAV 配置，并关闭自动同步。
   - 打开 popup，点击同步按钮。
   - 弹窗仍展示 WebDAV 同步服务项。
   - 服务项展示自动同步已关闭。
   - 点击同步按钮仍可以触发一次手动同步。

3. 未配置任何有效同步服务
   - 清空 WebDAV 必填配置，且未登录可用的云同步服务。
   - 打开 popup，点击同步按钮。
   - 弹窗展示配置同步服务的空状态。

4. 同步进行中
   - 触发 WebDAV 同步后立即打开同步弹窗。
   - 对应服务状态展示同步中。
   - 服务项内同步按钮置为同步中且不可重复点击。

5. 同步失败
   - 使用错误的 WebDAV 凭据触发同步。
   - 弹窗展示同步失败状态和错误信息。
   - 自动同步状态仍按配置开关独立展示。
