# 搜索匹配回归测试清单

用于验证 popup / quickSearch 的正式搜索，以及两处预搜索建议的关键词匹配规则。

## 1. 空格查询的顺序匹配

前置条件：

- 存在标题或标签包含 `AB` 的书签
- 存在标题或标签包含 `AXXB` 的书签
- 存在标题或标签包含 `BXXA` 的书签
- 存在仅摘要包含 `AB` 的书签

操作步骤：

1. 在 quickSearch 输入 `A B`
2. 等待预搜索建议列表出现
3. 按 `Enter` 执行正式搜索
4. 在 popup 搜索中输入 `A B`
5. 等待 popup 预搜索建议列表出现
6. 按 `Enter` 执行正式搜索

预期结果：

- quickSearch 预搜索能匹配 `AB`
- quickSearch 预搜索能匹配 `AXXB`
- popup 预搜索能匹配 `AB`
- popup 预搜索能匹配 `AXXB`
- 正式搜索能匹配 `AB`
- 正式搜索能匹配 `AXXB`
- `BXXA` 不应仅因为包含同样字符就匹配
- 仅摘要命中的书签不应出现在预搜索中
- 仅摘要命中的书签仍可出现在正式搜索中

## 2. 原有连续关键词匹配

前置条件：

- 存在标题或标签包含 `github` 的书签

操作步骤：

1. 在 quickSearch 输入 `git`
2. 在 quickSearch 输入 `github`
3. 在 popup 搜索中输入 `github`

预期结果：

- 原有包含匹配仍然生效
- quickSearch / popup 的预搜索和正式搜索均能返回相关书签

## 3. 拼音匹配不回退

前置条件：

- 存在标题或标签包含中文词的书签
- 存在仅摘要包含中文词的书签

操作步骤：

1. 在 quickSearch 输入对应拼音
2. 等待预搜索建议列表出现
3. 在 popup 搜索中输入对应拼音
4. 等待 popup 预搜索建议列表出现
5. 按 `Enter` 执行正式搜索

预期结果：

- quickSearch / popup 预搜索仍支持标题、标签的拼音匹配
- quickSearch / popup 预搜索不匹配仅摘要命中的书签
- 正式搜索按既有规则执行，不因本次空格匹配调整产生异常

## 4. URL 匹配

前置条件：

- 存在 URL 或 hostname 中按顺序包含多个查询片段的书签

操作步骤：

1. 在启用 URL 搜索的入口中输入带空格的查询
2. 对比预搜索和正式搜索结果

预期结果：

- URL / hostname 按原文关键词规则匹配，不使用拼音
- 多个查询片段需要按输入顺序出现
