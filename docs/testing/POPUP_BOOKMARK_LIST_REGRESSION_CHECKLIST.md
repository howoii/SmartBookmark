# Popup 书签列表回归测试清单

用于验证 `popup.html` / `popup.js` 普通书签列表的列表项交互与操作按钮显隐，避免样式调整影响打开、编辑、删除和批量编辑入口。

## 1. 默认列表项操作按钮

### 前置条件

- popup 普通列表视图中至少存在一个可编辑或可删除书签

### 操作步骤

1. 打开 popup
2. 观察书签列表项的右侧操作区
3. 将鼠标悬浮到某个书签列表项上
4. 将鼠标移出该书签列表项

### 预期结果

- 未悬浮时不显示编辑按钮和删除按钮
- 悬浮书签列表项时显示可用的编辑按钮和删除按钮
- 鼠标移出后编辑按钮和删除按钮再次隐藏
- 书签标题仍保持单行省略，不应与操作按钮重叠

## 2. 删除按钮行为

### 前置条件

- popup 普通列表视图中至少存在一个可删除书签

### 操作步骤

1. 打开 popup
2. 将鼠标悬浮到一个书签列表项上
3. 点击该列表项右侧的删除按钮

### 预期结果

- 删除按钮悬浮后可点击
- 点击删除按钮不打开书签链接
- 弹出删除确认流程

## 3. 批量编辑模式

### 前置条件

- popup 普通列表视图中至少存在两个书签

### 操作步骤

1. 打开 popup
2. 进入批量编辑模式
3. 悬浮任意书签列表项

### 预期结果

- 批量编辑模式下不显示单项编辑按钮和删除按钮
- 勾选框与选择状态仍正常工作
